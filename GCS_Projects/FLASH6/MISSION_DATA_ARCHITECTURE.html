롤 제어 알고리즘

1. 제어 루프 구조

롤 제어기는 롤각을 천천히 정렬하는 외부 루프와 롤각속도를 빠르게 추종하는 내부 루프를 직렬로 연결한 캐스케이드 구조로 구성한다. 외부 루프의 출력은 내부 루프의 각속도 기준값이며, 내부 루프의 출력은 카나드 믹서를 거쳐 네 개의 조향각으로 변환된다. 비행체의 롤 응답은 다시 롤각 φ와 롤각속도 p로 측정되어 두 루프에 동시에 피드백된다.

1.1 루프 신호 정의

기호신호의미
φ_cmd롤각 명령추종할 목표 롤각. 각도 명령을 사용하지 않는 경우 외부 루프를 생략한다.
φ측정 롤각자세 추정기가 계산한 +x축 기준 롤각.
p_cmd롤각속도 기준외부 루프가 생성하거나 상위 시스템이 직접 지정하는 목표 각속도.
p측정 롤각속도자이로 x축 각속도(gx)를 보정·필터링한 값.
eφ, ep각도·각속도 오차각 루프의 기준값과 측정값 차이.
u정규화 제어출력내부 PID 출력. 믹서 입력 범위는 −1에서 +1로 정의한다.
δ₁…δ₄카나드 명령믹서가 계산한 네 카나드의 최종 조향각.

각 샘플에서 자세 추정값과 자이로값을 먼저 갱신한 뒤 외부 루프, 내부 루프, 믹서 순서로 계산한다. 따라서 내부 루프는 외부 루프보다 빠른 응답을 담당하고, 외부 루프는 내부 루프가 충분히 안정화된 범위에서만 천천히 기준값을 변경한다. 모든 신호는 동일한 제어 시간 간격 Δt를 기준으로 계산한다.

2. 제어 법칙

제어 법칙은 롤각 오차를 먼저 각속도 기준값으로 변환한 다음, 측정된 롤각속도가 그 기준값을 추종하도록 조향 명령을 계산하는 순서로 구성된다. 이와 같은 캐스케이드 구조를 사용하면 외부 루프는 목표 자세 정렬을 담당하고, 내부 루프는 공력 교란과 순간적인 회전 변화에 빠르게 대응할 수 있다.

2.1 외부 롤각 루프

eφ(k) = wrap(φcmd(k) − φ(k))
pcmd(k) = sat(Kφ eφ(k), −pmax, +pmax)

wrap()은 오차를 −180°에서 +180° 범위로 접는다. 각도 명령을 사용하지 않고 각속도 명령을 직접 받는 모드에서는 외부 루프를 생략하고 p_cmd를 직접 사용한다.

2.2 내부 롤각속도 PID

ep(k) = pcmd(k) − p(k)
I(k) = I(k−1) + ep(k)Δt
uraw(k) = Kpep(k) + KiI(k) + Kd[ep(k) − ep(k−1)]/Δt
u(k) = sat(uraw(k), −1, +1)

미분항은 측정 잡음에 민감하므로 실제 구현에서는 오차 미분 대신 저역통과 필터를 적용한 p의 미분을 사용하거나, 필터 시정수 τ_d를 명시한다. 적분항은 출력 포화 방향으로 더 진행하지 않도록 조건부 적분 또는 back-calculation anti-windup을 적용한다.

2.3 카나드 믹서

δi(k) = sat(δtrim,i + mi Groll u(k), −δmax,i, +δmax,i)
i ∈ {1, 2, 3, 4}

m_i는 각 카나드의 단위 조향이 +롤 모멘트에 기여하는 방향을 나타내는 믹서 부호이고, G_roll은 정규화 제어출력을 실제 조향각으로 변환하는 이득이다. 카나드 위치는 1번 45°, 2번 135°, 3번 225°, 4번 315°로 기록하되, m_i의 최종 부호는 형상 시험으로 확인한다.

3. 카나드 배치와 롤 모멘트

네 카나드의 조향각은 개별 핀의 공력 효과를 합산하여 동체 x축 주위 모멘트로 변환한다. 동압 q, 기준 면적 S, 기준 길이 d를 사용하면 전체 롤 모멘트는 다음과 같이 표현할 수 있다.

Lx = q S d Cl     ,     ΔLx ≈ q S d Σi=14 Clδ,i δi

여기서 Clδ,i는 i번 카나드의 단위 조향에 대한 롤 모멘트 계수이다. 믹서 벡터 m = [m₁ m₂ m₃ m₄]T는 이 계수의 부호와 상대 크기를 반영하며, 서로 마주 보는 카나드는 반대 방향의 조향으로 순수 롤 모멘트를 만들고 다른 축 모멘트는 최소화하도록 구성한다.
