# ALTIS AVN Projects

ALTIS 항전 소프트웨어 작업공간입니다. GCS, 펌웨어, 공통 자료를 서로 분리해 관리합니다.

## 디렉터리

- `GCS_Projects/FLASH6`: FLASH6 지상관제 시스템과 웹·모바일 자산, 회귀시험
- `Firmwares/ALTIS_INTELLIGNET3_firmware`: ESP32-S3 PlatformIO 펌웨어 프로젝트
- `Others/Documents`: 공통 프로토콜, 미션 문서, 변경 이력
- `Others/Local_Artifacts`: 로컬 테스트 이미지와 임시 산출물

## 시작 위치

- GCS: `GCS_Projects/FLASH6/flash6.html`
- 펌웨어: `Firmwares/ALTIS_INTELLIGNET3_firmware/platformio.ini`

PlatformIO에서는 `Firmwares/ALTIS_INTELLIGNET3_firmware` 폴더를 프로젝트로 열어 사용합니다.
